# SamEvans03.github.io
This repository contains the code for my portfolio site. Additionally, we have all the SVG icons, images, and required imports stored in the assets folder of the repo. The skeleton HTML code was produced entirely by me using a few online tutorials and forums, the CSS styling was created using more tutorials and some generative AI help with specific bug errors and styling choices. 

In the process of creating this webpage, I believe it was important to begin with a clear design to ease the difficulty of the coding aspect, therefore, I created a mock-up using Figma, which is also attached inside the repo. This helped serve as the inspiration
